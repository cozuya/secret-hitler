# Season 25.1 patch note (Discord)

Ready to paste into Discord (under the 2,000-character message limit). Post it when the 25.1 release
goes live; it describes the same changes as the in-game changelog.

```text
**Season 25.1 update** :tada:

**New Player Game is playable again.** Opening it no longer bounces you back to the main lobby, so you can sit down and play. It also now always uses **speed mode**, like newly created games.

**Neighbor Chat changes**
- Neighbor Chat games are now **always casual**. They don't count for Elo or ranked wins/losses, and turning on Neighbor Chat sets the game type to Casual.
- New: whisper by **seat number**. Use `/4 hi` to message seat 4, as well as `/l` and `/r`. It only works for your nearest living neighbor on either side; anything else tells you which seats you can reach.
- The Neighbor Chat icon in the game list now sits with the other game mode icons, left of the timer.

**Previous government markers moved.** The yellow "Prev. P" / "Prev. C" tags now sit **below** the previous president's and chancellor's cards, so player names stay in place. The current or pending government token is unchanged.

As always, let the mods know if anything looks off.
```
